## 边界及真实修复

- 共用合同只描述数据及接口，提取模块只调用端口；文档证据模块不导入条款或提取实现。自动结构门禁同时检查本地导入是否可解析、源码软链接是否残留。
- `FactBundle` 校验文档修订、事实编号唯一性、映射引用、目标摘要和汇总计数；两类原值共享同一结果出口。原值先保存，组织失败单独记录。
- 标签/行业等报告登记信息可修订；执行时仍使用已冻结的文档引用。物理证据身份或内容变化拒绝继续；标签变化不替换阅读上下文。
- 取消后先为 `cancelling`，按实际队列子任务确认结束；准备阶段读取真实子任务状态，避免父级已取消而页面仍显示执行中。
- 观测失联与业务失败分开；确认进程死亡/身份复用才标中断。终态不显示仍在生成的模型阶段。两个 worker 与队列共用工作消息协议，修复原值已保存但队列误判失败的问题，完成/部分完成均有实际进程边界回归。
- 一份报告使用一个提交键；同键同输入幂等，输入不同拒绝。当前单编排进程保证提交锁；多进程扩展前需数据库唯一约束。
- 请求凭据不参与 DTO 序列化；OCR 请求/响应持久化过滤凭据和签名 URL。保留 provider JSONL 空行，避免物理来源行号偏移。
- 安装包在源码目录外验证 14 个模块导入，包含系统 OCR Swift 助手；不靠工作区软链接才能运行。

## Console 的实际结构

报告列表 → 报告详情；提取列表 → 单/批量向导 → 任务 → 条款结果 / 独立事实 → 证据；展示组 → 条款 → 单条合同；运行 → 队列任务 → 所属提取。返回与选项卡状态进入 URL。报告身份、导入、新增/编辑条款、证据均为独立弹窗。

请求去重、卸载取消、隐藏页面暂停轮询；读取/写入有时限，写操作不自动重放。表单提交期间禁用，乐观并发冲突保留输入，批量仅重试未提交项。弹窗有焦点管理、Escape、Tab、滚动锁及背景隔离。hover/focus 保持文字可读。

桌面 1360×900、窄屏 390×844 已实际核验。窄屏报告使用卡片，长事实表在本区滚动。运行页健康请求已修为 `/health/compatibility`，尚未取得状态时显示读取中。完整自动回归 13 项，另有浏览器操作证明；两者不是同一项检查。

## 仍不属于已完成能力

1. 37 条内容尚未决，其他模板也不代表科学验收；不能批量把 readiness 改为 ready 冒充效果达标。
2. 尚无全条款、多报告召回与准确率基准；最新真实试点仍为 partial。
3. 新事实审核、显式发布、数据库接收器仅规划，不恢复 Core 适配。运行中 PlatESG 8765 没有加载本轮退役源码。
4. 原规划的中立理解缓存已被后续要求撤销，不复用跨条款模型阅读。物理文档结构缓存仍由文档模块拥有。
5. 模型通用调用信封、统一能力协商仍是后续标准化建议；已有文档和提取输出协议不能被描述成全部统一。

本轮结构、接口、前端和当前生产链路已核验；上述科学内容与后续产品建设是明确列出的边界，并非隐藏在“全部完成”里的未决项。
