## 1. 被审计的运行

平台最新一次提取为中国石油天然气集团 2025 企业社会责任报告（96 页，定向读取 24 页，5 次模型调用，33 秒），16 项中仅 2 项有结论。

| 项 | 结果 | 判定 |
|---|---|---|
| E2-4_02 | VOCs 5.59 万吨（p90） | 正确 |
| E2-4_03 | COD 0.40 万吨（p90） | 正确 |
| NOx 8.2 万吨（p91） | 整表未映射 | **链路缺陷，本轮修复** |
| E1-6_07 | 候选 1.78 亿吨（范围一+范围二合并行） | 拒绝正确，拒因未显示，本轮修复 |
| 其余 12 项 | 未披露或仅方法/节约量 | 复核报告原文后确认，非链路缺陷 |

关键发现：第 91 页行标签为 `氮氧化物（NOx）排放量（万吨）`，旧 `_is_unit_like` 见到单位词即判定该列为单位列，导致整表无行标签、模型无从映射。这不是模型能力问题，而是表格解析层的通用缺陷。

## 2. 本轮改动

| 机制 | 位置 | 行为 |
|---|---|---|
| 标签列判定 | `tables._is_unit_like` | 括号内单位后仍有实义词的单元格属于标签列；单位列只放单位 |
| 污染行补全 | `kernel.pollutant_row_items` | 整表漏映射时按污染物词表提出行候选，交由守卫裁决，标 `row_label_names_pollutant` |
| 拒因保留 | `kernel.Observation.rejected_by`、`consolidate.brief`、`rejection_reasons` | “仅其他期间”附带真实原因（如 `label_is_combined_scopes`） |
| 成员属性 | `Observation.attributes` | 列标题路径、表标题、分区、单位来源、边界、期间标签；开放字典 |
| 条款规格 | `foundation/specs.py` | 声明式 `ClauseSpec`；16 项保持专用守卫，其余条款按规格判定，不再无条件通过 |

## 5. 已知问题

- **E1-6_07 的合并范围行**：拒绝正确，但报告若另有单列 Scope 1，仍可能被同一表的“TOTAL”行干扰；当前依赖标题/分区补全范围词，跨页标题缺失时会退化为候选。
- **p90/p91 之外的 KPI 信息图**：第 38、40 页的独立数字块（如“75 万吨标准煤”）不是表格，也未进入正文补查，因为它们是“节能量”而非目标指标；若未来条款需要这类块，需要新增块级数值解析。
- **污染词表仍是白名单**：未知污染物（如二噁英类具体同系物）会以清洗后的标签名作为成员名，可展示但不可聚合。
- **声明式规格尚未覆盖 16 项之内的边界情形**：16 项仍走专用守卫，规格层只服务新增条款；两者未来需要收敛为一层。
