# 阶段 3：共享文档能力与增量检索

日期：2026-10-28

## 已交付

- 原生文字层 + 布局检测不再限 foundation16：普通全文构建、显式页范围都可使用；
  扫描、图片表格、无布局 provider 仍按原视觉/自定义路线回退。
- 标准包提供 `retrieval_contract`：条款标签、概念别名、排除语义与单位轴生成检索意图。
  选页器支持从版本化合同注入关键词组，不再只接受 foundation16 的固定表。
- 新增 `ReportEvidenceStore`：按 document + IR run + revision 保存/复用中立事实与对象解释；
  新条款可复用同一 IR 的来源，不重跑全本 OCR，不混用不同 IR。
- 覆盖决策区分 `not_covered / unmapped / insufficient_evidence / confirmed_not_disclosed / covered`；
  只有证据充分才允许确认未披露，普通未命中不升级为确定结论。

## 真实验收

- 真实中国石油报告缓存首次保存 180 条中立事实，第二次复用 180 条，未重新读取报告。
- 单一条款只选相关页及必要报告期/身份上下文；没有相关页仍按原规则回退，不伪造覆盖。
- 文档 677 通过、提取 768 通过/6 跳过；缓存身份、冲突解释与 IR 隔离测试通过。

## 边界

- foundation 默认仍使用已验证的关键词族，新增条款走标准合同检索意图；
  不为“统一”删除已有效的报告语义适配。
- 中立理解缓存以 IR 版本为边界，旧结果不被新合同静默改写；
  复杂视觉修复仍按对象触发，未要求整页视觉复核。
- 阶段 4 把中立事实、观测维度、来源与覆盖决策形成科学数据产品和 CSV/Parquet 投影。
