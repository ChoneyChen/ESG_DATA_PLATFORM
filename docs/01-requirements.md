# 产品与需求

## 目标与范围

以完整报告和独立条款为输入，经可重复、可中断续跑、成本有界的链路，直接阅读报告原页，优先完整捕获原值、披露期间和单位。独立数据库接收后按明确政策组织产品，Console操作，Plat公开展示。条款、报告、阅读器、应用和数据库通过合同合理连接、独立演进。

范围包括条款管理、PDF资源、物理证据、两类提取、编排、交接、数据库投影、显式发布和展示。CrawlESG不接入。自动抓取、向量召回、条款成熟度/样本配额和自动发布不作为当前主干的完成条件。

## 要求及可观察行为

| 编号 | 要求 | 完成表现 | 责任 |
|---|---|---|---|
| RQ-01 | 单条内聚 | 一个clause.json提供定义、类型、属性、词典、检索、阅读、证据、用途和展示；新增条款不写指标专用分支 | ClauseESG |
| RQ-02 | 同一主干 | quantitative/qualitative决定同一页级协议及两类原值；16/32等只是ID集合 | extraction |
| RQ-03 | 原值优先、属性包容 | 种类、量、单位有安放位置；单位/主体/期间未知也保存实际值；丰富属性按字段保存 | contracts、extraction |
| RQ-04 | 全披露期间 | 2023/2024/2025各自保存；季度、财年、区间、时点和未知保留含义；主报告年不筛值 | extraction、database |
| RQ-05 | 来源可靠 | 模型按原页转录实际数值和陈述，保留页号供核查；可选属性缺失或无逐格引文时仍保存原值 | document、extraction |
| RQ-06 | 条款驱动搜索 | 页定位使用所选条款的别名和检索词；文档服务提供原生文字和页面图像 | ClauseESG、extraction、document |
| RQ-07 | 成本有界 | 同页合并读取多个独立目标，保留各年份。以页数、调用、输出和时间限制成本 | extraction |
| RQ-08 | 模型可配置、可解释 | 默认本地提取；文档视觉定位和主提取可分别显式选择模型。实际模型、模态、预算、tokens、耗时和失败可查。提供者选择随任务冻结，模型理解不跨条款复用 | runtime及消费者 |
| RQ-09 | 批量可管理 | 报告独立成会话。批次按提交顺序让最多十份报告进入执行窗口。报告结束后按序补一份。续读、取消与恢复保留实际进度和顺位 | pipeline |
| RQ-10 | 独立交接 | 封存包可以离开生产目录传输；接收有幂等回执；内部路径不是接口 | extraction、database |
| RQ-11 | 数据职责分层 | 原值保留所有期间/来源；比较、选源、重述、发布不反向删除测量 | database |
| RQ-12 | 清楚的操作界面 | 五类对象及父子页面、统一运行浮窗、按需分页结果表 | Console |
| RQ-13 | 清楚的公开展示 | 只读有效发布；原值、属性、期间、来源和精确导出可查；撤下不再公开 | Plat、database |
| RQ-14 | 统一维护 | 一套当前文档；同轮修改责任模块、合同和文档，移除替代内容 | 全仓库 |

## 术语与状态含义

资源信息描述报告企业、发表年、行业和文件身份；实际身份描述某值的期间、主体、场址、边界和方法；目标描述条款要找什么，三者不可代填。

事实是记录原 PDF 页号的定量或定性原值；条款关系是match/uncertain/different；覆盖是计划范围内的搜索结果；比较资格归数据库；发布是操作员采用明确成员/政策建立的产品。执行完成不等于全部条款披露、全部属性已得或内容全部正确。

## 使用过程

1. 制作/选择独立条款，导入完整PDF及已知资源资料。
2. Console 预览并冻结输入与条款，创建单份会话或按选定报告顺序创建批次。
3. 定位相关原页、直接读取各期间，保存两类事实及关系。
4. 封存并交接数据库，查询接收、投影和原值。
5. 预览成员和选源理由，显式发布，Plat读取发布快照。

RQ-01—14已有对应实现入口；不同报告形态的效果仍须依据真实任务判断。现有缺口集中在[质量与工作清单](10-quality-and-work.md)，不再把每次故障另立为总规划。
