# 本轮模块化、全年份与发布链路修复

依据：[10月31日M01–M15计划](../../audits/2026-10-31/README.md)、[原升级规划](../../../全链路检查报告与升级规划.md)及后续明确裁定。旧体系/旧字典/旧产物与旧格式读取清除；新运行自己的输入身份和当前产品成员不可原地改写，这不构成旧版本兼容通道。

本轮工程修改、全项目结构与逐文档复核、两份真实报告接收和投影已完成。隔离OCR派生样本的九个标注值也已通过；最终部署记录另列。这里的完成指本轮工程修复与明确范围验收，不是全报告召回率或1113个值条款科学验收全部完成。

[中文逐值基准](catl-final-benchmark.json) · [中文接收/科研回读](catl-final-integration.json) · [英文45值](ckh-final-benchmark.json) · [英文接收/科研回读](ckh-final-integration.json)。各文件记录实际运行ID和执行时指纹。另见[隔离OCR九值核对](controlled-scan-benchmark.json)：从原PDF第73页完整栅格化成一页无文字层PDF，本地Paddle实际识别，生成51条三年值，9目标/42其他，1次语义调用55.864秒。它与原生PDF候选范围和调用条件不同，不能直接用来声称提速。后续worker安装/执行计数的基础设施更新另经测试，不伪造它们的生产时间或改写其输入。

中文联合执行有一次4096-token截断和分帧重读，10次调用耗时956.513秒；英文最终2次291.196秒。先前英文紧凑试跑214.984秒不能替代最终观测。模型重复生成期间/主体等属性会放大成本；当前证明了可续读和数据不因可选属性被挡，**没有证明已经提速**。

实际搜索范围、候选与预算写在各运行证据中。九值、45值是指定标注区域的核对，52/222是接收规模，不是全部已逐条人工科学验收的数量。未搜索/未标注部分不计作全报告召回率。缺比较边界仍显示数据，不冒称可跨企业合并。

## 四、模块与文件设施

- ClauseESG拥有单条声明和SDK；Extract的合同、证据、骨干、调度各自拥有接口与状态；Console拥有操作组合；数据库拥有长期模式/接收/发布；Plat只读已发布产品。
- 模型worker在MLX与Paddle专用Python中离线安装本项目包，不再拼接兄弟源码或以源码目录作cwd。指纹由实际安装的包内容生成；[源码外验证](../../verification/standalone.json)确认worker入口、同摘要、数据库与Plat均不依赖Extract检出目录。[真实worker执行检查](../../verification/installed-worker.json)在临时数据根与明确的空文档端口执行、封存，0模型调用，不触及活动数据；它不冒充真实报告效果。独立单条原始输入无需组文件或选择集合，索引可生成，点名不存在的集合仍拒绝。
- 执行锁归shared_runtime，调度器和worker共同消费；无有效继承锁时worker在模型前拒绝。隔离扫描实测发现并修复Paddle环境缺少文档包的问题，OCR也改为模块入口；预检校验该模块，而不只检查权重。启动入口归ConsoleESG/scripts；跨模块开发检查归根tools。
- 旧字典、旧SQL/worker、冻结旧接口、旧IR/OCR读取和旧整页替换操作已删除。当前只支持Clause1.3/Catalog4、SourceFact2、FactBundle2.2、Organized1.1、Export1.1、Receipt1及IR0.12/当前包。
- [全项目文件清单](../../verification/project-structure.json)按所有权、角色、散列和导入核验第一方文件，排除Crawl、私有本地数据与第三方依赖。[30份逐文档记录](../../verification/document-review.json)逐一明确用途、版本裁定和当前链接；不是所有代码与1113条科学含义的逐行认证。
- 重复旧手册和千行旧操作日志收口，原需求、审查基线与必要日期证据明确标识；[文档清理](document-retirement.json)。原需求仍可追溯，不作为当前启动说明。
- [旧数据清理](runtime-cleanup.json)停机后移除19个旧根、10496文件、885597936字节，原18份PDF保留；后续被替代的调试轮次再清除，[最终调试清理](runtime-cleanup-final-trials.json)。[构建残留](build-cleanup.json)清除431文件/3033767字节，不删除有效运行环境或当前前端构建。

本机只有当前独立库，启动不初始化/迁移、不接管旧模式；显式新库初始化归数据库命令。来源保护事务与接收串行，原PDF引用受到保护；当前产品的来源ID不成为生产者目录依赖。Crawl未改动，自动发布关闭，无真实数据被公开发布。

## 六、两份制作说明

- [标准条款如何构造](../../guides/clause-authoring.md)：从完整模板填写单条，范围/词典/阅读/组织内聚，所有已披露期间与可选属性可安放。
- [PDF如何组织并导入](../../guides/pdf-intake.md)：完整原PDF、单次登记、批次manifest、实际散列和可选资源元数据；不按年份拆原件，不手改中间事实。

输入由这两类文件规范准备；输出的事实、证据、封存、回执、投影和发布成员由各所属模块生成，不靠人工搬JSON接数据库。
