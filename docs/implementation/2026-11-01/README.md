## 联调记录（2026-11-02，进行中）

当前源码已接通六项更新。最终一组任务尚在执行，以下将实现情况与真实结果分开记录。

1. **单条属性。** 属性定义、读取说明、值词典及补读词归独立条款。搜索计划、阅读卡、分类与结果组织分别引用；平台比较政策不再进入模型阅读卡。方法补读词不提供泛用默认值，具体条款需要时声明实际适用的词。
2. **增量生产。** 原值与条款关系逐条写入，运行进度单独更新。新任务在结束时只组装一次2.4原值包，不生成整份组织表；表格由结果接口按需组织。
3. **搜索与来源。** 按候选页推进检索，缺页交编排准备，再续跑原任务。每条事实及补读证据引用实际IR快照，多快照交接已由第三阶段165条真实接收证明。
4. **属性补读。** 模型只返回已有事实的属性和原文引用，不重新生成数值。补读失败或属性未陈述不阻断原值。中间实跑曾把水/蒸汽方法误用于能源，已去掉过宽的默认方法词并收窄报告范围词，正在用最终任务观察修复后的实际效果；中间试跑原件保留，没有覆盖其事实或发布。
5. **数据库比较。** 提取只输出捕获结果、目标关系及属性；数据库按冻结条款声明判断后续比较与选源，删除额外写死的主体、边界要求，逐观测处理适用范围。真实276条选源预览中，2023年90条、2024年93条、2025年91条、期间未知2条均保留；没有发布数据。
6. **分页展示。** 后端事实索引执行条款、期间、关系、单位和文本筛选；Console先读轻量概览，再读当前条款/当前事实页。当前页50行，单事实详情按ID读取，矩阵只表达本页数据。旧冻结结果只读取已保存内容，不重新编译旧条款。
