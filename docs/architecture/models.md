# 模型执行与搜索规范

模型语义分别属于文档或提取模块，执行通过 `ModelCallRequest / ModelCapabilities / ModelCallReceipt` 记录统一信封。它不是第三种事实值合同；定量/定性仍是两类。

| 任务 | 输入 | 输出与边界 |
|---|---|---|
| PP-DocLayoutV3布局 | PDF页及布局参数，image模态 | 区域、坐标、阅读顺序；不能输出ESG事实 |
| 本地PaddleOCR-VL | 不可读页/区域图像和OCR配置 | 文字、表格、坐标，转换为IR；不决定条款 |
| 系统Vision OCR | 扫描选页或局部补字 | 文字与位置；平台内部权重版本明确未知 |
| 本地Qwen定量 | 冻结条款阅读卡、文字帧、行列来源枚举 | 测量选择及目标关系；程序读取数值，模型不能重写数值 |
| 本地Qwen定性 | 同一条款边界、原文span | 精确原文，不自由改写，不由未命中生成未披露 |
| 显式IR审查/验证 | 局部图像、IR和受控补丁协议 | 提议修复，文档接收器决定应用；默认条款编排不启用 |

默认Qwen3.5-9B-4bit，温度0，当前条款阅读纯文字输入，grammar_schema。模型名含VLM不代表每次看图。文档本地审查与可选NuExtract使用各自worker输出协议，约束级别可能为prompt_schema加服务校验，不能冒充token级语法约束。远程适配器仅保留显式能力；本轮不切云，cloud OCR=false。

调用信封表达ID、任务/尝试血缘、实际模态、证据ID、提示词/Schema摘要、申请/有效预算、模型/provider能力、耗时、tokens、取消/失败和输出校验。提取、文档ModelRunner、OCR路由及实际布局/识别worker使用共用记录。有效预算在适配前裁定，提取默认申请4096、能力上限8192，时限取任务剩余和模型上限。成功输出通过专属DTO验证后才标validation=passed。凭据与完整prompt不放进公共信封。

本地推理仍允许进程内MLX和文档隔离worker两种执行机制，职责不同但共享调用记录；没有以合并所有模型进程为名增加队列绕路。权重可驻留，条款语义理解不能跨条款/运行复用。

## 搜索

`ClauseESG.compile_search_plan()`把本条词典、精确标签、正负词、必需词组、结构锚、候选类型和表/文优先级编译为SearchPlan。页级和对象级有各自执行语义；对象排除等不能作用整页的字段明确记为deferred。完整词项不因长度或数量被静默截断。

PDF先用原生文字选页；扫描或不可读回退识别。IR对象按词项、精确命中、结构、来源优先级排序。有界帧按候选/行分块；所有可辨识期间及列语义由结构提供，其余由模型。脚注的数字编号不是测量，正文真实计数即使没单位仍可接收。

当前没有embedding生产调用。是否增加向量召回应由标注漏召回和实际收益决定。物理OCR/IR在PDF散列、实际处理计划和版本一致时可复用，不把理解缓存恢复成物理缓存。`bounded_complete`只表示计划范围完成，不是全报告穷尽或未披露证明。

## 实际任务记录

更新后直接运行CATL多年份定量与定性、CKH宽表及实际补读/扩围任务，记录原值、关系、属性证据和接收结果，见[本轮记录](../implementation/2026-11-01/README.md)。

模型输入不含比较策略、报告企业或主年份默认值。未取得的属性直接省略；结构已有的年份继续由绑定器保留。大帧截断或超时会分帧续读；目标表中的未决遗漏行/列单独补读。属性补读按少量事实分批，只有明确声明的字段参与，缺失不使原值失败。

补读先提供该事实自身的行列来源、表题、章节与脚注，再提供条款检索到的报告说明。每个事实有自己的局部来源ID；报告说明另列，空字符串不当成已取得属性。证据层级来自物理来源，模型只选择属性及引文。已有证据读完仍有声明属性未取得时，才向编排请求文字上下文补页；补页不继承测量查询的负词和数字排序偏好。

续跑保留本任务已保存的物理帧引用、原值、错误和完成位置；失败帧保留重读位置，重读成功后清除该帧旧错误。这里没有跨条款或跨运行的语义复用。

多行列标题使用组合来源ID，模型引用其连续文字，绑定回到实际物理片段。每个补读批次只携带该批事实可用的局部来源和相关报告说明；返回后立即保存变更事实与批次位置，显示不必等待整条补读结束。

定性陈述的报告期关联只看所选原文，不能借用同一帧其他段落的“报告期内”；标准编号的版本年份不当作测量年份。补读响应显式返回assignments数组，没有可补属性时返回空数组，原值仍可接收。

属性可用的local/report范围声明在条款attributes.context_levels中；阅读器不把远处通用集团文字交给只允许局部来源的主体字段。没有局部报告期引用的期间未知项，不再触发无法继承的报告期补页；原值及未知状态仍保留。属性补读触及模型输出预算时，把事实组拆小重读，保留父调用与尝试记录，数值不重新生成。

所有队列worker必须带同一共享执行锁的有效继承描述符。执行锁归shared_runtime，调度器与模型生产者只消费这个通用能力；提取worker无锁时在读取/模型前拒绝，不另开并发通道。完整物理帧与紧凑模型输入分开，模型只引用实际显示的短ID；绑定仍回读完整证据。

条款属性字典负责编码解释；没有字典或未确认的文字不作为编码口径冲突。绑定器保留同一属性的多段说明和全部引用，逐事实汇总后更新，避免最后一项覆盖前面的总则或分项方法。

检索先读取当前快照的严格候选，目标未找到时才在预算内放宽对象词组；已有部分目标也继续定位条款计划内尚未准备的页。未命中时才放宽页查询的必含词组。新页准备仍归编排层，阅读继续使用原任务ID，直到候选耗尽或本次预算用完。可选属性缺失不构成搜索完整性的硬性要求。

补页响应分别列出新页和已准备的相邻结构页；编排将其一同交给文档构建，让横向续表保留前页行名、单位及列头。提取按本任务已取得的物理单元保留原事实ID，只读取新增或含义未决的数值。完整物理帧按实际快照保存，补读可引用同一PDF其他快照中与该量值或陈述对应的物理上下文。

运行汇总由提取模块的RunStatistics随事实及映射变更更新。补读只提交改变的事实，读取位置独立保存；热路径不再扫描全部原值进行汇总，结束时从结果仓储组装一次交接包。恢复只读取本任务已保存的原值与位置。
