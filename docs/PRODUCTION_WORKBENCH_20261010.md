# 数据生产工作台：管理与批量自动化

更新：2026-10-10。本轮落实访问说明、记录和文件管理、批量自动生产；历史完整源码回滚不作为产品推进前置条件。原编号、标准定义、核心条款与主要条款的区分保持不变。

## 工作台访问密钥

原界面的“审核凭据”是工作台访问密钥。它用于服务器识别操作员，并授予读取、审核、发布或管理权限，不是审核意见、模型密钥或OCR密钥。

本机默认密钥位于 `PlatESG/.local/review-token`。在终端执行，将实际密钥直接复制到剪贴板，然后在顶部“连接工作台”中粘贴：

```sh
pbcopy < "/Users/choney/Desktop/ESG  Database/ESG_DATA_PLATFORM/PlatESG/.local/review-token"
```

界面的复制按钮只复制这条终端命令；网页不直接读取本机密钥文件。服务器验证后显示操作员和权限。自定义部署使用管理员分配的密钥。凭据仅保存在当前页面内存；刷新网页需要重新连接，断开连接也清除页面中的模型凭据。公开数据网站不携带工作台密钥。

## 记录与来源管理

报告库、报告处理、提取任务、历史独立任务和统一队列直接提供管理入口；动作依据拥有记录的后端返回。列表默认隐藏归档记录，可切换查看并恢复。

| 操作 | 效果与条件 |
|---|---|
| 删除记录（可恢复） | 归档记录、从默认列表隐藏，保留来源和修订 |
| 恢复记录 | 根据最新修订恢复；丢弃过的处理记录还需验证原来源完整性 |
| 取消执行 | 请求停止，等待子进程实际退出后才释放资源 |
| 批量整理 | 逐项核查生命周期和修订，确认后归档允许项；失败项和原因独立显示 |
| 中间缓存回收 | 绑定已核实的原生提取会话，先核查引用和计划，再确认可恢复回收；保留PDF、OCR、IR、规范成果和调用记录 |
| OCR／IR文件回收 | 报告详情“处理与证据”和系统运行中查看文件、规模、引用阻塞及计划；仅执行未过期且被后端允许的计划 |

活动任务、数据库来源引用或引用无法确认会阻止相应回收，界面显示具体原因。中间缓存恢复清单可在重新打开页面后读取；“计划缓存规模”不等于已经释放的磁盘量。

归档PDF仅隐藏它：已冻结批次仍可使用该PDF。停止已有批次使用暂停或取消。未结束的批次保护所引用PDF，防止尚未开始处理的来源被回收。仍被生产阶段需要的处理记录也不能提前丢弃或归档。

## 批量自动生产

入口为工作台“自动生产”：`http://127.0.0.1:18081/#/automation`。

1. 选择多份已有PDF，或批量上传并登记报告。按已登记年份、报告名称自动排序，再用上下按钮调整。没有登记年份的报告排在最后，不从文件名补造年份。
2. 配置统一处理模式、生产终点和失败策略。需要提取时选择主要、核心或自定义条款范围，沿用原编号和批准的延伸定义。
3. 核对整批预览中的报告、身份修订、范围、顺序和阻塞。全部满足条件后，一次提交父计划；可以立即执行或保存待部署。

| 生产终点 | 自动衔接 |
|---|---|
| 报告处理 | 严格复用兼容成果，或完成OCR和DocumentIR，保存可用证据 |
| 处理＋定向提取 | 处理完成并通过证据条件后，自动开始所选条款提取 |
| 处理＋提取＋候选交付 | 再交付冻结成果到候选审核；每份报告需确认标题、发布主体和报告期间 |

父计划按提交顺序推进，每批按冻结顺序逐份完成所选链路。模型工作继续使用现有唯一重任务队列，人工已排队任务与自动化子任务共用该队列。待执行报告可重排，在途和已完成报告不能移动。

默认失败后继续其它报告，也可暂停等待处理。详情显示逐报告真实进度、阶段链接、阻塞和事件；无可计算进度时明确显示未知。暂停停止后续派发，让已启动阶段收尾；取消请求停止已有子任务并等待实际退出。失败重试沿已有子任务恢复接口继续，不重新提交已成功报告。结束的父计划可归档和恢复，子任务、成果与来源保留。

计划保存PDF SHA、报告修订、处理配置、引擎版本和标准范围快照。预览后输入或标准改变需重新预览；运行期间不会静默换标准或PDF。创建和派发用稳定身份防止重复；重启后沿已保存阶段恢复。

本轮持久批次支持本地处理及本地提取模型。批次合同拒绝云配置，不保存模型或OCR访问凭据；现有单报告云任务入口保留。候选交付使用工作台权限，凭据失效或服务重启后等待重新连接并恢复；已完成处理和提取不会因此重跑。

## 审核和发布

自动化的终点最多是候选交付。事实审核、标准映射审核、发布条件检查和正式发布继续独立。证据不足、主体／期间／口径未知不会因批量执行变成合格记录。

自动生产读取和预览需要读取或管理权限，部署和管理需要管理权限，候选交付另需审核或管理权限。后端再次核查权限。
