# 阶段 2：中立事实、全期来源与字段级证据

日期：2026-10-28

## 已交付

- foundation 每个实际数值单元格可形成独立中立 SourceFact：原值、单位、期间、边界、行标签、物理来源与字段证据；
  未映射行与历史期间也可保留，但不自动获得条款归属或批准。
- 真实 foundation 会话把该集合写入成果包 `reported_facts`，与条款映射 SourceFact 分开。
  standard 路线继续使用既有中立理解/条款映射，不另造第三套事实模型。
- 数据库 `fact_role=neutral` 保存跨条款/跨期间的来源快照；不自动创建候选披露。
- 交付去重保留物理事实与来源引用，解释变化/新 IR 形成不可变快照；
  值、主体、期间、单元格/坐标变化仍原子拒绝。`component_*` 明细可补充，不覆盖原披露。
- 公开 Observation 显式输出 `identity_evidence` 与 `source_fact_refs`；
  证据修订参与测量上下文/观测身份，旧发布不被改写。

## 真实验收

- 中国石油隔离 Bundle：180 个中立来源事实，144 个历史期来源，5 个炼化边界；条款候选为 0。
- 独立金标：当前期 3/3、历史期 12/12、污染物维度 15/15；炼化边界保留，集团未知不补造。
- 宁德时代 49 个真实 Bundle 跨 IR/组件补充回放：33 条映射、28 条自动批准、5 条待人工；
  不再因同一单元格的不同解释整包回滚。未发布。
- 公开字段证据与来源引用已通过真实导入→机器核验→显式隔离发布→公开 DTO 验证。
- foundation 全量 764 通过/6 跳过；相关数据库、导入、公开 Observation 合同通过。

## 与下一阶段的边界

- 全期来源不是“当前期批准”，未映射来源不是“负例通过”。报告细分类与条款固定分类分别保存。
- 阶段 3 将复用报告级中立事实/证据索引做增量检索，避免新增条款重新全本 OCR；
  选页词与检索也迁入条款合同。
- 阶段 4 将把 `neutral` 快照和字段证据形成稳定的科学表/CSV/Parquet 投影；
  当前正式库未迁移，新增 migration 只在隔离 PGlite 验证。
