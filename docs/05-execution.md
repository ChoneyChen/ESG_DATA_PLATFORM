# PDF与提取执行设计

适用 RQ-02—09。执行主干见 [engine.py](../ExtractESG/extraction/src/esg_extraction/pipeline/engine.py)。目标是以尽量少的模型调用读全实际披露。

## 端到端过程

| 步骤 | 输入与处理 | 所有者 |
|---|---|---|
| 选择与冻结 | 原 PDF 或关联原件的已有 IR、独立条款、两阶段模型和预算形成会话快照 | pipeline、Clause SDK |
| 文档定位 | 读取整个原件的原生文字，按条款短语、词项及相邻页列出候选。已有 IR 可提供页提示，扫描或文字稀少页可选视觉定位 | document 原页接口、extraction 页计划 |
| 主提取 | 完整页图和辅助文字与同页待填条款一起交给视觉模型。同次读取印刷值、原句、各期间、单位及声明的可选属性 | extraction、任务指定 ModelPort |
| 增量结果 | 解析可解析的原值和期间，保存关系和 PDF 页号。检查点记录已读页、待处理页及调用总数 | result_store、statistics |
| 封存交接 | 已冻结目标、来源及两类事实组成独立封存包，接收、投影与发布继续由数据库负责 | exporting、delivery、database |

## 页计划与预算

同一页聚合多个待填目标，各条款独立解释。每条优先取原生文字排名前 8 页，保留排名前三的相邻页、词项匹配明显的数字密集页和文字不足页。条款找不到关键词时，先读取全报告内共享的优先页及数字密集页。已被纳入的数字密集表页可附上具有文字匹配的其他条款，并受该条款页数预算约束，使用同一次页面读取。任务复用已登记 PDF 的清晰原页，普通新提取可直接进入排队，已有 IR 只影响页提示。纯文字模型开启后以可搜索页为输入。

可选文档视觉阶段只为文字不足页生成提示，每次最多 6 张缩略图，最多 8 次调用且受任务总调用额度的五分之一约束。模型页提示用于排序。主提取使用原页大图与原生文字，避免逐条逐格发请求或读取后再发属性补读请求。主模型以表格行为单位返回多个期间值，程序逐值保存。当前表页没有年份列头且前一页原生文字有多年份表头时，同次调用提供前一页列头与缩略图，模型按视觉版式判断是否为同一续表，并只转录当前页量值。历史实绩与目标列各自带关系及适用属性。单位保留原印刷倍率、化学标记和分母，叙述“没有排放”等语句不生成数值零。输出截断或结构无法读取时按同页条款拆分，单条款截断时保留已完整返回的行。没有实测原值的项目保持空白；缺可选属性可以形成原值。

阅读卡提供实际字段和目标判别字段，规范单位留在条款合同。模型同时读印刷标签、量值和单位，从相关脚注保留人群限定及适用年度。模型把多个各带明确年份的限定合写到同一实际字段时，提取保留唯一适用于该年度的原词。缺关系的原值保留为未决。单条明确声明可识别的已实施做法时，阅读 SDK 可以用这段原句补足关系，同时保留原句及未知属性。已分类的字段与同一条款的固定目标口径冲突时，原值归为不同口径。来源只写 Revenue 时照录收入分母，将净收入和范围 2 方法留在实际已知程度。

PipelineBudget 默认 128 次模型调用、每条 100 页、4096 输出 tokens 和 14400 秒。模型运行以实际额度为限。状态区分页计划覆盖、预算结束、读取失败和实际返回的条款关系。一个已读页没有匹配项时继续候选。任务不会依据报告主年抹掉其他披露期间。

## 独立 OCR 与 Document IR 工具

先保留完整PDF身份与页序。文字可搜索时用原生文字定位，扫描/不可读页使用本地识别。PDF预检、布局、文字观察、表格融合、坐标、章节、表头、续表映射均属物理层。稀疏准备保留原PDF页号。

物理TableIR表达实际网格；LogicalTableIR用source_cell_ids连接确定的跨页单元格，不创造量值。横向续表必须能对应实际行，不能以假定行偏移掩盖不确定；表头组合保留各片段来源。同页上下表或相邻页无重复表头的续表须同时满足列数、外框对齐、标签/单位/数值列结构及无新标题等条件，读取投影沿实际连接回取前表年份cell与页号，子表首行仍保留。具体对象可读不代表整个报告或所有图表均已读好。

原生文字表格不能用正文中孤立的百分比推断全表测量列；有实际横向分隔线的政策/说明表按线恢复完整行。共享语义已确认的完整长单位不受短词长度启发限制，保留印刷表达式与原单元格。该物理构建修复需要重新准备生成新OCR/IR，不改写旧包。无分隔线或扫描识别错列仍须按真实来源判断。实际rowspan父标签与单位从覆盖网格携带原cell_id，单位被分成多格时绑定各个印刷片段。千分位数1,999作为量值，只有实际年份表头才参与期间识别。

年份表头与首个数据行落在同一横线带时，分别保留其基线和行；同一表头行的不同字形基线按实际行成员保全。独立的单位倍率行即使没有左侧标签，也只沿紧邻后续测量行的同一单位列连接，保留倍率和单位两个实际cell来源。标签上下有实际横线、内部横线只穿过右侧单位和数值列时，按该合并格恢复rowspan，保留居中标签覆盖的各测量行及单位。真实1999/2000等数量通过本行标签、单位及日期轴区分，Disclosure year等日期列保留时间含义。抬高字形按原字体大小、基线及相邻公式/单位识别，m³等单位中的指数依附其实际字符。

报告期间优先回读明确的期间声明，日期范围须与本句报告期间标签或报告呈现范围相连，比较和目标期间不能抢占声明。英文日期范围只在末端印年份时，起止日期共用该实际末年，保存完整范围原文及声明block来源。共享期间解析保全年/区间类型，逆序且省略年份的区间保持unknown，不能只绑定末日期；报告期间引用使用繁简折叠匹配，保存原句不变。比较往年表现的句子不作为报告期间声明；期间缺失时继续保留来源所支持的未知或回退依据。

NativeFigureTextBuilder从PDF物理词观察保全图内文字、印刷数值、图例及换行，记录词索引和坐标，原FigureIR继续保留。完全覆盖的重复片段退役时保存snapshot和引用映射。text_geometry按基线及横向间距形成真实片段，唯一对齐原文后提供字符范围和来源词字框，原生字号与基线使年份及抬高脚注分别保留。共同底线、相同宽度的独立柱形及实际凸闭合路径内的唯一量值可建立标签column关系，所属图区的标题和单位作为region辅助来源。图形范围内的普通近邻仍保持未决。

evidence_service将混合单元格中的局部量值暴露为可选EvidenceCell，保留原cell对象、页号及字符范围，原cell全文继续可读。纯数字、完整单位及已识别单位列、参照列沿其原类型处理。same_clause关联依据筛选和分段前的完整量值清单生成，同一句内各量值均保留原句共现关联，口径适用性仍由本次阅读选择和条款守卫判断；原生图形使用实际几何关系。

标准索引表中，实际Disclosures列与同行标准号优先证明披露编号类型。同行缺少标准号时，只在披露格以编号开头且该前缀实际印在同一表的标准列时，识别本格同前缀编号。同格真实量值继续保留。正文和混合单元格在枚举数值候选前，先按原字符范围识别页码、网址、标准号、分类编号、脚注、明确期间和复合单位中的倍率。月份和年份复用共享期间解析，单位倍率结合实际单位表达式及位置判断。范围、温度、科学记数、带单位的年形量值和语境未能确定的数量继续参与阅读。印刷的复合单位倍率即使不完整，来源文本和位置也原样保留。仅包含已确认参照字面的说明单元格保持非测量类型。

独立文档工作流可以生成 OCR 与 IR。显式IR复核使用OperationRegistry、review-plan-v3、review-operation-payload-v2提议局部修订，事务生成新修订，不原地修改旧包；这与条款提取、业务发布是不同过程。

## 调度、状态与续跑

**批次窗口按报告计。** 一个批次最多十份报告参与共享队列。前十份按提交顺序入窗，其余停在候补状态，保留冻结请求和批次顺位。入窗后从准备、排队到阅读结束一直保有席位，切片续读不会释放。完成、部分结束、失败、取消或中断进入终态时，会话状态与下一份候补入窗在同一事务写入。数据库异步接收和投影独立进行。取消候补无需创建原生运行；显式续跑沿用原会话和冻结请求，重新等待席位。

**阅读切片按模型调用计。** 会话、队列任务与原生阅读分别持久化。一份报告续读沿用同一队列任务和原生运行。每个切片最多 10 次模型调用。派发时的等待任务数为 0、1–3、4–9、至少 10 时，时间目标分别为 45、30、20、12 秒。完成至少一次调用后，提取器用本切片已耗时和平均调用耗时判断还能否启动下一次调用。已运行的调用完成后才让出槽位，保留任务总预算、页计划、游标、已填原值和计数。

编排在有两类等待时交替派发文档准备和提取。同类按实际进入等待的时间安排，首次等待从建任务计，续读从上个检查点完成计。手工优先级在下一次领取时消费。同一次派发与工作台等待顺位使用相同规则。普通候选等待期间保留已读数。取消结束会话和它拥有的活跃任务。进程断开后可用本次已存的窗口和真实 worker 回执恢复，历史带准备子任务的会话沿用原生命周期。续跑使用冻结输入和版本，升级后已有结果可读，使用新任务执行新版。

## 模型调用

| 能力 | 使用位置 |
|---|---|
| PP-DocLayoutV3、PaddleOCR-VL 本地、系统 Vision OCR | 独立文档 OCR / IR 工作流 |
| Qwen3.5-9B-4bit 本地 MLX | 默认主提取，可选文档视觉定位 |
| DeepSeek Flash 官方 API | 可选文档视觉定位和主提取，接收对应页图和相关提示 |
| DeepSeek V4 Pro 官方 API | 可选纯文字主提取 |
| 显式 IR 审查及 NuExtract | 独立文档能力 |

两阶段配置独立冻结。已显式选用 DeepSeek 的阶段把该次阅读所需的页图或文字发送到官方接口。密钥只用于后端发起请求。调用记录包含阶段、页号、实际模态、提示及 Schema 摘要、耗时、预算和错误等信息。模型提供者出错时不静默切换。模型理解不跨条款或任务缓存。

本地 Qwen 的返回解析兼容 JSON 属性名内的首尾空格。解析阶段保留字段内容原样，印刷单位、年度和量值继续使用共享读取合同。定量缺失说明保持空白，报告印刷的零作为原值保存。
