## PDF物理准备

先保留完整PDF身份与页序。文字可搜索时用原生文字定位，扫描/不可读页使用本地识别。PDF预检、布局、文字观察、表格融合、坐标、章节、表头、续表映射均属物理层。稀疏准备保留原PDF页号。

物理TableIR表达实际网格；LogicalTableIR用source_cell_ids连接确定的跨页单元格，不创造量值。横向续表必须能对应实际行，不能以假定行偏移掩盖不确定；表头组合保留各片段来源。同页上下表或相邻页无重复表头的续表须同时满足列数、外框对齐、标签/单位/数值列结构及无新标题等条件，读取投影沿实际连接回取前表年份cell与页号，子表首行仍保留。具体对象可读不代表整个报告或所有图表均已读好。

原生文字表格不能用正文中孤立的百分比推断全表测量列；有实际横向分隔线的政策/说明表按线恢复完整行。共享语义已确认的完整长单位不受短词长度启发限制，保留印刷表达式与原单元格。该物理构建修复需要重新准备生成新OCR/IR，不改写旧包。无分隔线或扫描识别错列仍须按真实来源判断。实际rowspan父标签与单位从覆盖网格携带原cell_id，单位被分成多格时绑定各个印刷片段。千分位数1,999作为量值，只有实际年份表头才参与期间识别。

年份表头与首个数据行落在同一横线带时，分别保留其基线和行；同一表头行的不同字形基线按实际行成员保全。独立的单位倍率行即使没有左侧标签，也只沿紧邻后续测量行的同一单位列连接，保留倍率和单位两个实际cell来源。标签上下有实际横线、内部横线只穿过右侧单位和数值列时，按该合并格恢复rowspan，保留居中标签覆盖的各测量行及单位。真实1999/2000等数量通过本行标签、单位及日期轴区分，Disclosure year等日期列保留时间含义。抬高字形按原字体大小、基线及相邻公式/单位识别，m³等单位中的指数依附其实际字符。

报告期间优先回读明确的期间声明，日期范围须与本句报告期间标签或报告呈现范围相连，比较和目标期间不能抢占声明。英文日期范围只在末端印年份时，起止日期共用该实际末年，保存完整范围原文及声明block来源。共享期间解析保全年/区间类型，逆序且省略年份的区间保持unknown，不能只绑定末日期；报告期间引用使用繁简折叠匹配，保存原句不变。比较往年表现的句子不作为报告期间声明；期间缺失时继续保留来源所支持的未知或回退依据。

NativeFigureTextBuilder从PDF物理词观察保全图内文字、印刷数值、图例及换行，记录词索引和坐标，原FigureIR继续保留。完全覆盖的重复片段退役时保存snapshot和引用映射。text_geometry按基线及横向间距形成真实片段，唯一对齐原文后提供字符范围和来源词字框，原生字号与基线使年份及抬高脚注分别保留。共同底线、相同宽度的独立柱形及实际凸闭合路径内的唯一量值可建立标签column关系，所属图区的标题和单位作为region辅助来源。图形范围内的普通近邻仍保持未决。

evidence_service将混合单元格中的局部量值暴露为可选EvidenceCell，保留原cell对象、页号及字符范围，原cell全文继续可读。纯数字、完整单位及已识别单位列、参照列沿其原类型处理。same_clause关联依据筛选和分段前的完整量值清单生成，同一句内各量值均保留原句共现关联，口径适用性仍由本次阅读选择和条款守卫判断；原生图形使用实际几何关系。

标准索引表中，实际Disclosures列与同行标准号优先证明披露编号类型。同行缺少标准号时，只在披露格以编号开头且该前缀实际印在同一表的标准列时，识别本格同前缀编号。同格真实量值继续保留。正文和混合单元格在枚举数值候选前，先按原字符范围识别页码、网址、标准号、分类编号、脚注、明确期间和复合单位中的倍率。月份和年份复用共享期间解析，单位倍率结合实际单位表达式及位置判断。范围、温度、科学记数、带单位的年形量值和语境未能确定的数量继续参与阅读。印刷的复合单位倍率即使不完整，来源文本和位置也原样保留。仅包含已确认参照字面的说明单元格保持非测量类型。

普通条款准备不自动执行全报告VLM精修。显式IR复核使用OperationRegistry、review-plan-v3、review-operation-payload-v2提议局部修订，事务生成新修订，不原地修改旧包；这与条款提取、业务发布是不同过程。

## 搜索与排序

Clause SDK从retrieval、exact_labels及明确引用的reading.vocabulary生成页/对象计划。阅读规则判断含义，不自动把所有规则正向词铺成泛滥搜索词。文档服务只消费通用查询，不导入Clause SDK。

页级先短语定位，必要时用通用词项匹配处理英文词形/括号；无关键词的可搜索报告不能触发整本重新OCR。对象先主候选，未命中再走条款词项/词典候选。正文与表格按条款声明的来源优先级排序。

定量混合表仅用含实际数值候选的行（包括未解析的科学记数原文）参与最佳局部行评分，结合共享标题和列头；仅共享文字命中而本行标签未命中时降权，缺少可读测量行的表也降权。负向词作用于当前行标签和section，可识别数值与条款允许单位种类提高相关性；未知单位不直接排除。定量文字对象取逐句得分的最大值，保留同对象其他句子的原文。参考标准编号、页号、日期和化学式数字不当测量值。

模型调用前，文字和混合单元格也执行本条款已有的正向require_any/require_all；有强关联时逐量值读取完整标签组及获关联的region标题，无强关联时检查实际原句与同对象语境。任一可选来源满足正向条件即可保留该行。缺单位、期间或强关联本身不排除原值候选。负向词与最终量纲判断留给模型选择后的局部绑定，避免混合父段落中的其他测量排除真正目标。

普通表格行的局部解释优先使用本行的分组标题。无分组标题时，只有本页实际来源唯一印有精确表标题，才将其用于候选、模型行级上下文和最终绑定。绑定保存该标题的原文和位置。缺乏明确来源时继续使用本行已有证据，混合量值仍按局部关联协议读取。

## 两类模型协议与绑定

定量主阅读返回`matches: [{row_id, columns, match?, unit_source_id?, label_source_id?, context_source_ids?}]`。默认match是目标命中，含义或目标本身模糊时使用uncertain。unit_source_id可选择帧内真实单位声明的引用，数值、单位字串及其他属性由绑定器回取。结构给出实际所有年份/列语义，模型读取所有相关行和已披露期间。

decisions按当前帧生成引用枚举和数组上限。定量matches最多为实际单元格总数，columns最多为实际不同列数，context_source_ids最多为实际关联来源数；定性matches最多为实际文本片段数，Schema同时声明条目唯一；实际解码器对uniqueItems可延后处理，不能据此声称多行重复均已拒绝。数组长度上限由grammar执行。上限随帧内全部期间和来源扩展，约束重复引用扩写，同时容纳全部已提供的真实列和量值，分段仍受实际模型预算管理。

定性返回`matches: [{span_id, quote?, match?}]`。quote是可在该span唯一回读的完整原句；未提供时选择整个span。不把标题/索引/话题短语当回答，不把搜索未找到变成“未披露”。判断只使用所选引句及直接行列标题，原单元格未选的其他句子不能补足目标语义；完整原文仍保留供查阅。文字对象暴露逐句span，约4000字符的阅读分块按完整句子打包，不在字符边界砍断句子；超长单句由真实模型输入预算约束，不能把切碎句子冒充完整陈述。重试也只在句界拆单span。引句允许唯一的纯空白差异对齐，保存的原句及字符位置始终回取物理原文；改字、缺字或歧义仍拒绝。

绑定器回读物理原字串，单位取实际单元格、列头、行标签、表题及所选印刷单位片段。百分号后缀同时保存为原单位。保留印刷单位和倍率，换算归后续使用。真实0保留，空白/斜线不变0。文字候选保留完整句子语境，父标题括号中的单位倍率、GRI/NSF等参照列、明确地址编号和时间表达先在物理层标识，避免数字形状冒充测量。换行构成真实字符边界，下一行数值不会接成上一行英文标识符。字段只按其实际证据绑定，报告企业、主年或目标固定分类不能代填实际身份。

文字及混合单元格的量值保留原object_id与字符范围。完整原文供模型阅读，numeric_context要求label_source_id属于该量值的same_clause、row或column来源组，并回取整组标签及换行限定词；context_source_ids补充获关联的标题、期间或单位，region仅提供辅助依据。文字帧所选unit_source_id须完整落在获关联来源的字符范围内且逐字一致，紧随量值的单位按实际字符位置回绑。未证明量值与标签或所选单位的适用关系时仍保存原量并标uncertain。关联及来源ID随分段、重试和检查点保留，属性补读继续使用已保存事实的局部证据。表格纯数值行沿用原行列协议。文档在完整量值清单上建立same_clause来源。模型选择来源ID，提取按链接回取完整来源组。只有一个same_clause来源时，选择该量值即可确定其原文。图形row/column来源组继续整体绑定。同一标签仍同时包含多个独立GHG Scope时表达歧义，紧邻括注限定和重叠别名不虚构第二个Scope。两个方法与多个数值按respectively对应而缺少独立证据时保留未决。

2.14移除定量模型自由生成label_quote的出口。文档只在标点和连接词明确、两侧均有各自印刷主语和数量谓词且量值带单位时预切连续来源。括号内部、关系从句、条件句和respectively共用限定不做这一切分。数量加accounting for占比等依存句维持完整句，保留真正分子和实际分母。未能可靠分开的并列量值保持原上下文，由现有守卫确定关系或保留未决。旧决定仍可通过原字与边界校验回读。

链接到短子句后，完整父句保留供模型理解，只有原句前缀中的明确期间可以随子句绑定。子句未自带期间或显式报告期引用时，明确位于原句开头的“In YYYY,”、中文年份或报告期前缀保留为独立原文证据，维持其共同期间；子句自身日期或报告期引用优先。两个片段各自保持原字符位置，不拼成虚构的连续引文。

印刷千分位逗号后的空白属于量值原文，解析后仍保存原字串。明确Note/脚注编号及悬挂括号段号保留非测量类型。英文和中文倍率逐单位计算，双语印刷单位须有一致的量纲与倍率。含化学式的完整单位及其前置写法保存实际印刷片段。

一个来源表的历史列、主体列和方法列分别安放，不能合并成一条“最新值”。区间原文、比较符和上下界有位置；解析不成功仍保留原文。ClauseMapping不覆盖SourceFact。

## 默认局部边界

唯一策略实现：[reading_policy.py](../ExtractESG/extraction/src/esg_extraction/pipeline/reading_policy.py)。运行写入`input/reading-policy.json`，不是从本表读取配置。

| 行为 | 默认值及停止点 |
|---|---|
| 主候选 | 每个已准备来源最多4个对象 |
| 词项候选 | 每个来源最多4个额外对象；物理内容去重 |
| 命中对象 | 完成全部既定主候选及其分段/历史列；首次命中不截断其他实体或总量对象 |
| 单条补页 | 未命中才请求，最多1轮、4个新页 |
| 全报告补页 | 最多8个额外新页；已准备相邻页可参与续表构建 |
| 可选属性 | 仅match事实、仅已准备证据；每条最多2次模型调用 |
| 补读批次 | 4096输出预算下按约384 tokens/事实分组，约10条/批，仍受2次总额限制 |

请求总预算另由PipelineBudget限制：默认128次模型调用、每条100对象、4096输出tokens、14400秒。局部策略不会增加总预算。同一条款/事实/属性尝试过后，不因全局上下文变化重复补读。缺属性保持未知，不再为属性启动OCR。属性输入携带只读原值及实际期间，供模型把局部目标/方法说明对应到具体事实；输出仍只允许属性，不生成量值。具有分类词表的声称必须逐项取得引文证明，不能把裸指标名当actual，也不能将互斥角色合并成一个已知分类。

属性来源按每个事实、每个属性生成attribute_sources。直接行列和真实关联脚注供local读取，报告段落按本属性补读词授权。标号脚注依据当前行列/标题的引用，不向同表其他测量借用。报告级目标声称须同时回读该原值和期间。开放字段值回绑原句，value_pattern约束由本条声明，拒绝记录进入模型调用诊断。

阅读范围由每来源主候选及请求总预算共同界定。未命中才增加词项候选和补页。已访问帧与物理来源去重保留到续跑，其他主体和披露期间有独立的读取机会；候选边界外的明细仍由真实搜索覆盖表达。reading-policy-1.1检查点记录target_found，旧selected_object/object_complete显式迁移为已命中状态，已访问帧及原事实身份继续使用。

## 调度、状态与续跑

会话编排和原生运行各自持久化。准备和阅读共享执行资源，通过队列安排OCR、IR和提取；提取在保存调用/分段边界协作让出执行槽。未读分段、已选对象、补页轮数、尝试属性、累计调用与真实完成条款写入检查点。

queued表示排队；running还需结合current_phase区分准备与阅读；completed表示本次有界流程结束；partial表达具体执行/预算问题；interrupted表示服务/进程中断；failed保留真实错误；cancelled由取消流程结束。不要只看一个status判断数据质量，汇总还分别表达搜索范围、原值及属性。

文档连接或5xx错误作为DocumentUnavailable向上返回，中断并保留进度，不能继续把所有条款标完成。完成数来自completed_clauses，不是选中数或已有coverage记录数。恢复续跑同一任务与冻结目标；升级执行代码使用显式交接工具，不能偷换已冻结输入。

取消会话同时处理原生阅读和文档准备子任务；应用组合启动前收敛已取消会话的遗留子任务。worker退出后必须排空最终日志字节，包括读到EOF与观察退出之间写入的result，不能因文件尾竞态伪报无结果。协调器处理批量快照的每条会话时，在锁内重取当前状态，终态或已确认的取消不被旧快照覆盖成失败。基于批量快照重派已结束子任务前，重新确认原生任务仍排队，避免陈旧快照重复派发。模型worker继承有效执行锁，不能绕过队列另开模型通道。空闲休眠保护仅限任务执行期，不能保证合盖后继续计算。

准备引擎指纹依据实际导入的OCR、IR、配置及合同模块计算，模块名作为稳定键。源码环境与安装包使用相同的身份算法，数据根和安装目录变化不替代代码版本变化。
