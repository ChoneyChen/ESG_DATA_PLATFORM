# PDF与提取执行设计

适用RQ-02—09。当前主干版本在[engine.py](../ExtractESG/extraction/src/esg_extraction/pipeline/engine.py)；本基线为clause-backbone-2.7。策略、模型能力和合同版本分别有自己的来源，不能混作一个版本号。

| 5 阅读选择 | 冻结阅读卡+局部帧→行列或原句引用 | reading_frame.py、decisions.py、本地ModelPort |
| 6 绑定原值 | 实际引用→SourceFact、ClauseMapping、覆盖 | binding.py、period_binding.py、SDK规则 |

## PDF物理准备

先保留完整PDF身份与页序。文字可搜索时用原生文字定位，扫描/不可读页使用本地识别。PDF预检、布局、文字观察、表格融合、坐标、章节、表头、续表映射均属物理层。稀疏准备保留原PDF页号。

物理TableIR表达实际网格；LogicalTableIR用source_cell_ids连接确定的跨页单元格，不创造量值。横向续表必须能对应实际行，不能以假定行偏移掩盖不确定；表头组合保留各片段来源。具体对象可读不代表整个报告或所有图表均已读好。

普通条款准备不自动执行全报告VLM精修。显式IR复核使用OperationRegistry、review-plan-v3、review-operation-payload-v2提议局部修订，事务生成新修订，不原地修改旧包；这与条款提取、业务发布是不同过程。

## 搜索与排序

Clause SDK从retrieval、exact_labels及明确引用的reading.vocabulary生成页/对象计划。阅读规则判断含义，不自动把所有规则正向词铺成泛滥搜索词。文档服务只消费通用查询，不导入Clause SDK。

页级先短语定位，必要时用通用词项匹配处理英文词形/括号；无关键词的可搜索报告不能触发整本重新OCR。对象先主候选，未命中再走条款词项/词典候选。正文与表格按条款声明的来源优先级排序。

定量混合表按最佳局部测量行及共享表头评分，负向词作用于该行，不因同表另一行耗水/取水就处罚回用水。可识别数值与条款允许单位种类提高相关性；未知单位不直接排除。参考标准编号、页号、日期和化学式数字不当测量值。

## 两类模型协议与绑定

定量主阅读返回`matches: [{row_id, columns, match?}]`。默认match是目标命中，只有含义/目标本身模糊才uncertain；不返回量值、单位、属性和长理由。结构给出实际所有年份/列语义，模型读取所有相关行和已披露期间。

定性返回`matches: [{span_id, quote?, match?}]`。quote是可在该span唯一回读的完整原句；未提供时选择整个span。不把标题/索引/话题短语当回答，不把搜索未找到变成“未披露”。判断只使用所选引句及直接行列标题，原单元格未选的其他句子不能补足目标语义；完整原文仍保留供查阅。

绑定器回读物理原字串，单位取实际单元格/列头/行标签/表题；保留印刷单位和倍率，不在捕获时暗中换算。真实0保留，空白/斜线不变0。字段只按其实际证据绑定；报告企业、主年或目标固定分类不能代填实际身份。

一个来源表的历史列、主体列和方法列分别安放，不能合并成一条“最新值”。区间原文、比较符和上下界有位置；解析不成功仍保留原文。ClauseMapping不覆盖SourceFact。

## 默认局部边界

唯一策略实现：[reading_policy.py](../ExtractESG/extraction/src/esg_extraction/pipeline/reading_policy.py)。运行写入`input/reading-policy.json`，不是从本表读取配置。

| 行为 | 默认值及停止点 |
|---|---|
| 主候选 | 每个已准备来源最多4个对象 |
| 词项候选 | 每个来源最多4个额外对象；物理内容去重 |
| 命中对象 | 读完该对象全部分段和历史列后停止向其他对象扩张 |
| 单条补页 | 未命中才请求，最多1轮、4个新页 |
| 全报告补页 | 最多8个额外新页；已准备相邻页可参与续表构建 |
| 可选属性 | 仅match事实、仅已准备证据；每条最多2次模型调用 |
| 补读批次 | 4096输出预算下按约384 tokens/事实分组，约10条/批，仍受2次总额限制 |

请求总预算另由PipelineBudget限制：默认128次模型调用、每条100对象、4096输出tokens、14400秒。局部策略不会增加总预算。同一条款/事实/属性尝试过后，不因全局上下文变化重复补读。缺属性保持未知，不再为属性启动OCR。

这是集中披露的生产边界；分散在其他对象的明细可能未收全，后续能力改进要以真实报告收益决定，不能靠无限加页和调用解决。

## 调度、状态与续跑

会话编排和原生运行各自持久化。准备和阅读共享执行资源，通过队列安排OCR、IR和提取；提取在保存调用/分段边界协作让出执行槽。未读分段、已选对象、补页轮数、尝试属性、累计调用与真实完成条款写入检查点。

queued表示排队；running还需结合current_phase区分准备与阅读；completed表示本次有界流程结束；partial表达具体执行/预算问题；interrupted表示服务/进程中断；failed保留真实错误；cancelled由取消流程结束。不要只看一个status判断数据质量，汇总还分别表达搜索范围、原值及属性。

文档连接或5xx错误作为DocumentUnavailable向上返回，中断并保留进度，不能继续把所有条款标完成。完成数来自completed_clauses，不是选中数或已有coverage记录数。恢复续跑同一任务与冻结目标；升级执行代码使用显式交接工具，不能偷换已冻结输入。

取消会话同时处理原生阅读和文档准备子任务；应用组合启动前收敛已取消会话的遗留子任务。模型worker继承有效执行锁，不能绕过队列另开模型通道。空闲休眠保护仅限任务执行期，不能保证合盖后继续计算。

## 模型职责及调用记录

| 能力 | 当前用途 | 明确边界 |
|---|---|---|
| PP-DocLayoutV3 | 页面区域、坐标和阅读顺序 | 不输出ESG事实 |
| PaddleOCR-VL-1.6本地运行时 | 必要页/区域识别 | 文字/表格/坐标，不判断条款 |
| 系统Vision OCR | 文本预扫/局部识别能力 | 系统内部权重版本未知 |
| Qwen3.5-9B-4bit本地MLX | 默认定量、定性和可选属性读取 | 阅读卡/证据纯文字，grammar_schema，不生成数值 |
| 显式IR审查、NuExtract及远程适配器 | 可选能力接口 | 不属于默认条款阅读路径，不自动切换启用 |

ModelCallRequest/Capabilities/Receipt记录调用ID、任务/父尝试、实际模态和证据ID、prompt/schema摘要、申请/有效预算、模型/provider、耗时、tokens、取消及失败。输出约束级别按实际能力记录，prompt_schema不冒充token语法约束。

模型权重可驻留，物理OCR/IR可按内容和配置复用；模型理解不跨条款/运行复用。当前主干没有embedding生产调用。日志与公共信封不含凭据和完整敏感prompt。
