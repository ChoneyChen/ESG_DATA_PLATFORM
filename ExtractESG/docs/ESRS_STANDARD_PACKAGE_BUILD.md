实施日期：2026-10-04。输入底表：用户指定 IG3 文件，SHA-256 `90f15872c489786d86c445d8dc02e00783eb16ecd998d6e1f5a43ad48edd8be9`。原始 Excel 未修改。

## 1. 两种选择层级

- **核心条款**：某一披露小号包内，在理解该披露要求时优先关注的条款。每个已建包都有明确原编号清单及选择理由。
- **主要条款**：数据平台当前阶段选中的条款，必须属于对应包的核心条款；不会自动纳入全部包内核心。
- **语义角色**：`anchor/detail/context/derived/presentation` 描述事实在披露族中的作用。核心/主要选择与该角色、法定义务、May、重要性及phase-in分开。
- 当前主要条款严格采用用户注释二的 **49 个原编号**。范围3、方法、政策等仍在清单，不沿用上轮16项MVP删减。

`profiles/esrs/2023-set1/platform-major.json` 保留49项。未指定主题时，因33项属于未建主题，范围编译明确拒绝执行；只有显式 `--topics E1 E2 E3` 才输出本轮可用16项。其余33项以显式过滤排除清单保留。

包内核心配置在 `profiles/esrs/2023-set1/package-core/`。全量环境配置在 `environment-all.json`，覆盖322个独立原编号。所选输出、内部计算依赖、同包解释上下文、跨包共用引用分别返回；只有所选输出计入覆盖分母。

## 4. 原表、语义与版本分别保存

每条metric的 `provenance` 保留原表页、行、全部原始单元格、列头、原类型、May、条件、法规交叉引用、阶段性安排及行hash。`source_datapoint_id` 与原值第一个单元格一致。目录与原Excel全部1,184条逐行复核。

必要的规范性解释写入类型合同及 `semantic_type_note`，不覆盖原目录：E1-5能源强度、E1-8每吨碳价格、E3-4净收入水强度和其他强度、E3-3生态阈值、MDR目标基准值/年及BP-2重述差额分别处理。原表E1-5_19继续保留；后续勘误及新标准只能经独立版本和明确迁移应用。

`measurement_contract` 描述模板、实际/目标/基准/预期属性、单位与规范化资格、身份轴、比较条件、聚合限制、排除概念。它为后续入库/比较提供合同元数据；本阶段不执行币种转换、不发布规范观测。百分比规范为ratio时原值仍保留；储水变化与重述差额允许负数；水量不能跨概念替代，强度不能缺分母。

`core/1.2.0` 只增补通用单位；六类结果记录不变。新包统一格式2.1，编译器兼容历史1.0/1.1/2.0。原E1-5/E1-6/E2-4的元素、关系和派生合同保持，新增可审计元数据。2.0及本轮初次静态draft 2.1.0归入 `.retired`，历史任务仍可按版本加载。2.1.1在内容复核中补齐混合叙述/数值的decimal绑定、带符号差额及当前/未来值属性；编译器对新版本拒绝文本绑定到value_numeric。

标准来源区分法律、EFRAG官方复现及非权威IG3：[2023/2772法规](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX%3A32023R2772)、[EFRAG Set 1官方复现](https://xbrl.efrag.org/e-esrs/esrs-set1-2023.html)。中文为工作释义，原英文与段落继续可核验。

## 5. ESRS 2 / MDR 共用接口

位置：`src/esg_standard_packages/scope.py`。接口不调用模型，不构造业务事实。

| 接口 | 输入 | 返回与约束 |
|---|---|---|
| `load_registry(root)` | 标准库根目录 | 原始目录、注册表、经过校验的固定版本包；全量覆盖与引用校验 |
| `compile_profile(root, profile_path, topics=None)` | 主要/核心/全量profile与显式主题过滤 | 原编号、输出/执行/内部依赖/上下文列表及ReportExtractionRequest的standards字段 |
| `resolve_context_requirements(package, source_datapoint_ids, packages)` | 调用包、所选原编号、已加载包 | ESRS2/MDR-M目标包及版本、digest、原编号、内部ID、适用条款、用途，全部context_only |
| `resolve_shared_requirements(package, registry, packages, adopted=None)` | 调用包及明确采纳状态 | MDR政策/行动/目标的已采纳或未采纳分支；状态未知时只返回条件引用，不能激活事实 |

共用引用固定target版本和digest，不复制条款定义：

- BP-1提供编制基础、合并及价值链范围。
- BP-2及MDR-M按数值/混合条款提供方法、不确定性、变更与重述；必须关联被测指标。
- E1.GOV-3引用GOV-3，但一般可持续薪酬比例不能替代气候薪酬比例。
- 主题IRO-1引用ESRS2 IRO-1；E1.SBM-3引用SBM-3背景。
- 财务影响包引用SBM-3当前/预期财务背景；能源排放水量包引用SBM-1行业收入背景，收入总额不能自动作净收入分母。
- MDR-P/A/T按主题及政策/行动/目标对象复用。原表空DR的未采纳引用仍为空DR，解析器按明确主题和用途关联，不回填原表。

身份至少绑定主体、期间与报告边界；共用政策/行动/目标还绑定可持续主题和对应对象。具体事实不能因为读取了共用定义就自动带上默认主体、年份或方法。

上下文接口预留报告读取接入点；当前已有ReportSession请求可接受编译范围，2.1语义卡读取测量合同。跨包上下文报告事实的自动调度、审核入库和UI选择控件属于后续连接阶段，不把接口预留说成业务闭环已验收。

## 6. 重建、检查与范围使用

以下命令在standard_packages目录执行，使用安装本项目及依赖的Python。

```bash
PYTHONPATH=src python scripts/build_esrs_environment.py --publish
PYTHONPATH=src python -m esg_standard_packages catalog-check --root .
PYTHONPATH=src python -m esg_standard_packages profile-compile \
  --root . --profile profiles/esrs/2023-set1/platform-major.json \
  --topics E1 E2 E3 --output /tmp/platform-major-e1-e3.json
PYTHONPATH=src python -m esg_standard_packages profile-compile \
  --root . --profile profiles/esrs/2023-set1/package-core/e1-1.json \
  --output /tmp/e1-1-core.json
PYTHONPATH=src python -m esg_standard_packages profile-compile \
  --root . --profile profiles/esrs/2023-set1/environment-all.json \
  --output /tmp/environment-all.json
PYTHONPATH=src python -m pytest -q
```

构建仅使用仓库内冻结目录和显式语义内容，不依赖个人桌面路径、Excel库或联网。先在临时目录编译全部41包及校验注册引用，再安装；已发布源版本和编译版本内容不同均拒绝覆盖。批次内每个编译产物原子发布，注册检查负责发现批次中断导致的不完整安装，可重跑恢复；不声称跨41文件的数据库事务原子性。

范围示例保存在 `examples/scopes/`。衍生依赖是显式计算合同的闭包，可能包括操作数的操作数；不是同主题条款全开。直接披露优先与缺值时调度的运行优化在后续链路连接阶段完善。

## 7. 后续包建设门槛

每个占位含所有原编号、DR、拟纳入的主要条款、非执行状态及后续任务。未来主要条款必须进入该包核心；其余核心选择须完成整包语义分析，当前标为pending_full_module_analysis，不用空包冒充完成。

后续仍按一披露小号一个包，使用六种统一模板：数值、维度表格、类别、定性主张、政策行动目标、财务影响。新框架先登记独立标准版本与原编号目录，再复用合同、概念、接口及scope编译；禁止复制提取引擎或给报告/条款号增加专用分支。
