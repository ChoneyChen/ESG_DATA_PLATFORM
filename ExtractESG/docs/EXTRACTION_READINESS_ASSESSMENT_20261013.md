## 当前最主要的风险

1. **OCR/IR 上游错误可传递。** 绑定到一个真实 OCR 单元格只证明引用存在，不能证明该单元格与 PDF 数字一致。
2. **复杂概念的归属仍需判断。** 范围 1＋2 合计、地点法／市场法、取水／耗水、总计／分项、实际值／目标、强度／绝对量容易混淆。标准包已有排除规则，仍需真实样本验证执行效果。
3. **必要身份缺失会降低可用覆盖。** 保留数值候选是合理的；正式观测需要主体、期间、单位、边界和必要方法。不能把未齐身份默认为集团年度，也不能把“待确认”误报为完全没有提取。
4. **E3 身份层次需要校准。** 标准包含 geography、water_risk_class、measurement_method 等身份轴，平台基础总量的必需维度较少。应依据原条款适用条件区分“适用必需”“条件必需”“可选补充”，保持标准要求，不通过无条件补默认值提高通过率。该点本轮只记录，未悄悄改动标准合同。
5. **默认链路优先局部可用成果。** 主要指标入口使用本地模型、balanced、允许有限证据，关闭必要／可选模型复核。可以减少前置阻塞；扫描件及复杂表格的数字、表头仍需要核对，不能仅凭 ready_with_limits 入库。
6. **真实准确率与成本尚无新基准。** 预设模型响应和合成企业观测验证的是工程行为。它们没有测出真实模型的精确率、召回率、修复开销或运行稳定性。

## 首次新报告应怎样验收

维持全部原编号及配置。先在当前范围内核对清晰总量，再核对复杂口径，按风险逐步扩大验收；不修改主要条款清单。

1. 新选独立报告，人工从 PDF 标出对应条款的数值、单位、年度、主体、口径及证据页。包含明确未披露项、显式零和近似但不等价的披露。
2. 核对每条候选的原值、单位／尺度、期间、主体／边界、方法、条款归属及 PDF 证据。任一关键字段错误均不能算正确记录。
3. 分别记录：正确候选／全部候选、找回正确记录／实际披露目标记录、完整身份记录比例、审核后可发布及可比较比例。未披露条款不进入召回率分母，Scope 3 等多维条款按实际记录数统计。
4. 记录任务完成／中断、模型调用、修复调用、总时间和人工修改量。错误定位到 OCR、IR、来源理解、语义映射、单位规范或发布合同，按同一根因改进整层。
5. 在第二家企业及第二期间重复验证，确认没有跨年度、集团／子公司及方法混比，再扩大规模。

本周优先保持 PDF → OCR → 结构 → 所选主要条款 → 原文核对 → 候选审核入库的闭环。界面和任务管理改进服务于这条闭环；当前不继续把全面提取当作产品上线的前提。
