# 报告资产中心

本轮围绕 PDF 到主要指标提取的实际入口更新，标准包、原始数据点编号及主要指标范围不变。

## 使用入口

- 工作台默认进入“报告资产”。PDF 是父节点，展开查看多个 OCR 版本，再查看每个 OCR 的结构证据及修订。
- 来源关系由文件 SHA256、处理记录及明确的 run ID 建立；同名文件不能证明继承。缺少关联的 OCR、结构成果单独展示，仍可删除。
- 第一次处理 PDF 使用自动处理；已有 OCR 的“识别新版本”使用 `reprocess`，确实创建新版本。主要指标提取沿用原范围配置。
- 右下角处理状态悬浮窗继续展示统一队列及批量生产状态。

## 操作权限

查看报告、OCR、队列状态和公开数据网站无需 token。顶部“操作权限”验证本机操作员后，按角色开放生产任务、删除、候选读取、审核和发布。模型 API key 在模型配置中设置。token 仅保存在当前页面，不写入浏览器持久存储或链接。

## 删除规则

- 删除 PDF：删除原文件、该来源的 OCR、结构成果及关联本地执行记录。
- 删除 OCR：删除所选 OCR、所属结构修订及关联本地执行记录；PDF 和其他 OCR 版本保留。
- 删除结构版本：删除所选版本及后续修订、关联本地执行记录；PDF 和 OCR 保留。
- 删除执行记录：真正删除所属 SQL 状态、事件和固定引用；独立来源资产由资产中心管理。
- 活动任务删除先停止关联执行，真实退出后自动清理。接口返回 `202 / deletion_pending` 时仍未完成删除；只有 `deleted:true / status:deleted` 表示完成。
- 多报告计划只剪除所属报告，保留其余报告的固定调度身份，避免误删或重复执行。
- 已进入数据库的事实、证据快照和正式数据集独立于本地文件。删除本地来源不会连带删除正式观测；删除期间使用短期来源保留锁，完成后释放，同一来源可以重新上传、处理。

## 验证边界

仅使用临时合成资产验证版本继承、级联删除、兄弟版本保留、记录引用释放、活动任务停止后删除、来源再次处理及 SQL 快照保留。另做服务接口、授权、生产构建和只读运行检查。未使用中国石油失败结果做验收，未启动真实报告或模型质量测试。
