# 可选延伸条款

延伸条款是项目定义，归属于一个已有标准包，使用独立的 extension ID 和定义版本。它不冒充 ESRS 原编号，也不修改用户提供的 IG3 原目录。

当前建设状态：

- 当前 41 个标准包、512 个原条款、49 个平台主要原编号保持不变。
- `authoring/esrs/2023-set1/e1-6/scope1-scope2-total/1.0.0/` 保留绑定父包2.1.1的原草稿；新 `1.0.1/` 绑定父包2.1.2，含义及计算规则不变，必须重新独立审核后才可选择。
- 此处 `registry.json` 是随源码提供的作者草稿索引，目前没有静态批准版本。业务批准、登记和主要选择由发布数据库保存，`ExtractESG/.local/extensions` 是该权威登记的可恢复运行投射，不能根据作者目录判断实际启用状态。
- 当前本地业务库已批准上述合计延伸 1.0.0 并加入主要选择。定义登记和测试通过不代表真实观测已提取或发布；实际验收状态见 [P4–P7 实施记录](../../../docs/WORKBENCH_P4_P7_IMPLEMENTATION.md)。
- `schemas/` 从可执行 Pydantic 合同生成；每次合同变更须同步生成，测试检查两者完全一致。

延伸稳定身份为 `project.esrs.2023-set1.e1-6.extension.scope1-scope2-total`；已登记版本及新草稿版本分开管理。历史批准身份为：

`project.esrs.2023-set1.e1-6.extension.scope1-scope2-total@1.0.0`

它链接 E1-6_07、E1-6_09、E1-6_10，明确固定父包版本和内容摘要。父包保持 E1-6，一个延伸不产生另一个披露小号标准包。

代码接口位于 `../src/esg_standard_packages/extensions.py`，完整接入合同、权限边界和验收要求见 [EXTENSION_CONTRACTS.md](../docs/EXTENSION_CONTRACTS.md)。
