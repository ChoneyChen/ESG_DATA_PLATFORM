# 主提取模块

输入是独立的条款合同和文档引用，输出是两类原值事实、条款关系及独立导出包。条款定义、词典、范围和阅读规则来自 `esg_clauses`；本模块不维护指标名单。条款集合只是多个独立目标的选择。

定量模型选择物理行列，定性模型选择可引用原文。量值、原单位、年份和位置从证据绑定，模型不生成数值。原值合同为 `quantitative` 与 `assertion`；主体、范围、方法等可选属性不构成原值准入条件。

定性含义按所选原句及直接关联的行列标题判断，不借同一单元格中未选的其他句子补足目标语义；完整来源仍保留供查阅。候选排序归文档模块，词项和允许的单位种类由条款搜索计划提供。

## 阅读边界

默认策略在 [reading_policy.py](src/esg_extraction/pipeline/reading_policy.py)，并随每次运行写入 `input/reading-policy.json`：

- 命中目标对象后，读完该对象的全部分段和历史年份，停止向其他对象扩展。
- 未命中时，每个已准备来源最多读取4个主候选、4个词项候选；每条款最多一次扩围、4个新页，全报告额外定位最多8个新页。已准备的相邻页可作为续表上下文。
- 只为已命中的事实补充可选属性，每条款最多2次模型调用；使用已准备证据，不为补属性新建OCR任务。
- 补读进度按本任务、本条款、事实和属性记录；已尝试的属性不因全局上下文摘要变化而重新读取。
- 达到边界后保留原值与未知属性。完成执行代表完成这套有界流程，不代表穷举全报告或证明未披露。

运行总调用、对象和时间预算仍来自请求。局部策略不会增大请求预算。

## 文件职责

| 文件 | 职责 |
|---|---|
| `reading_policy.py` | 阅读边界、命中对象、扩围与补读进度 |
| `retrieval.py` | 消费条款搜索计划，获取有界候选 |
| `reading_frame.py`、`decisions.py` | 两类模型输入和引用选择合同 |
| `binding.py`、`period_binding.py` | 实际量值、单位、期间、引句和上下文绑定 |
| `enrichment.py` | 已有证据上的可选属性补充 |
| `engine.py` | 组合上述步骤，保存事实并协作续跑 |
| `adapters/`、`runtime.py`、`worker.py` | 文档与模型接口、存储和运行环境 |
| `exporting.py` | 按共享合同封装输出，供数据库模块独立接收 |

单位表达式与种类归共享数据层 `esg_data.units`；条款含义判断归条款SDK。新条款内容应扩展条款合同，通用执行行为应修改本模块相应组件。
