# PlatESG · 已发布科学数据与审核

2026-10-29：当前 PDF 提取生产者已经换为独立条款和两类原值事实。PlatESG 保留已有 SQL 数据、冻结字典、审核与发布产品；**新事实格式的数据库接收器不在本轮接入**。现有库没有重置或迁移。

现版字典是 `catalog/metric-dictionary.v1.json`，版本 1.5.0，共 55 项。它是既有产品的冻结定义，不能用来覆盖新的条款源。旧字典构建脚本、标准包登记、Core/Bundle 导入、交付重试及演示造包入口已退役；相关写入口返回 410 或明确的退役错误。

| 模块 | 职责 |
|---|---|
| `backend/` | 公开读 API、事实与映射审核、口径确认、报告发布和 SQL 适配 |
| `catalog/` | 已有数据产品的冻结指标定义和来源记录 |
| `backend/migrations/` | 平台自有 `plat` 对象；不提供新事实接收器 |
| `frontend/` | 企业、指标、比较、证据及已发布报告 |
| `review/` | 内部审核入口 |
| `tests/fixtures/` | 仅供隔离测试的虚构 SQL 消费者样例；不依赖条款包或生产导入 API |

公开接口：`/v1/entities`、`/v1/metrics`、`/v1/observations`、`/v1/coverage`、`/v1/comparisons`、`/v1/sources`、`/v1/datasets`、`/v1/exports`。数据集和证据按发布版本冻结；十进制数通过字符串传输。来源 PDF 必须通过来源散列与库内位置核对。

内部审核、口径确认、报告发布、撤下和产物管理使用受权限保护的 `/internal/v1/`。审核记录不能自动等同于发布；默认 `PLATESG_AUTO_PUBLISH=0`。数据库工作进程只有在显式设置为 `1` 时才在启动阶段处理发布队列。

完整模块边界和本轮逐条核验见[模块规范](../docs/CLAUSE_BACKBONE_REBUILD.md)与[更新报告](../模块化重构与逐条核验报告.md)。本轮未改建 Console，旧创建及标准表单尚未接新 API；不能通过恢复旧包或重新造历史产物使其继续工作。
