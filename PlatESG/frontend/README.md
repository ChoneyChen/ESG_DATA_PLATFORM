# 发布数据前端

当前界面以已发布数据集为入口，子页面查看观测及原文证据。只调用 `/api/v2`，不再读取旧指标字典或旧版本接口。

- 数据集列表 → 数据表 → 单条事实；每层有返回，浏览器前进/后退可恢复数据集与事实链接。
- 默认全部期间，期间/条款筛选只作用于查询和下载；不裁剪提取数据。
- 原值按精确字符串展示，包含零、区间和定性原文；缺可选属性仍可见。
- 证据显示物理页码，PDF通过已发布来源散列解析。公开状态由后端确认，撤下后不回退旧数据。
- CSV/Parquet下载交给数据库科研导出，页面不换算、聚合或重算比较资格。

`@esg/database-contracts` 是数据库DTO生成的类型SDK。客户端无SQL或提取文件路径依赖。代码按页面、通用UI、HTTP和导航组织，没有旧图表或审核模块。

```sh
npm ci
npm run dev
npm test
npm run build
npm run format:check
```
