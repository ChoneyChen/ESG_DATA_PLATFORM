# ConsoleESG · 数据生产操作台

独立 React / TypeScript / Vite 应用，是整个系统**唯一的人工操作界面**：报告、提取、审核、发布都在这里完成。
公开数据展示由 [PlatESG](../PlatESG/README.md) 承担。

操作台只消费后端合同：不解析 PDF、不调用模型、不决定事实。PDF 读取与条款提取由
[ExtractESG](../ExtractESG/README.md) 的两个服务完成，审核与发布由 PlatESG 的内部接口承担。

## 运行

```sh
npm ci
npm test        # 221 项合同与交互回归（隔离 HTTP，不调用模型）
npm run build   # 产物 dist/，由项目启动器在 18081 提供
npm run dev     # 开发入口 5180（需先起三个后端）
```

| 前端代理 | 上游 | 用途 |
|---|---|---|
| `/document` | 18080 | 资产、连续处理、报告会话、标准目录、唯一队列 |
| `/targeted` | 18180 | 固定证据、条款投影、事实与成果 |
| `/publication` | 8765 | 候选、审核、口径、发布与数据版本 |

代理上游可用 `CONSOLE_DOCUMENT_URL`、`CONSOLE_TARGETED_URL`、`CONSOLE_PUBLICATION_URL` 覆盖。

## 页面

| 路由 | 职责 |
|---|---|
| `#/reports` | **① 报告**：上传 PDF、按读取状态筛选、每行一个主行动（提取/重新提取） |
| `#/reports/{asset_id}` | 报告详情：概览、原文、处理与证据、提取、审核、发布记录 |
| `#/extractions` | **② 提取**：会话卡片（状态、条款进度、已形成事实） |
| `#/extractions/new` | 新建提取：选报告 → 选指标集（基础 16 / 重点 32）→ 开始 |
| `#/extractions/{session_id}` | 提取详情：指标成果、来源事实、阶段与运行、交付审核 |
| `#/review`、`#/review/{mapping_id}` | **③ 审核**：来源证据、事实审核、映射审核、按指标合同生成的口径表单 |
| `#/publication` | **④ 发布**：发布阻塞、交付收据、冻结版本与覆盖决定 |
| `#/automation` | 工具 · 批量生产计划（固定处理 → 提取 → 候选交付，勾选即加入并自动按登记年份排序；身份缺失就地提示并可跳转补齐，条款从指标集同步或自定义） |
| `#/standards` | 工具 · 标准包与原编号 |
| `#/processing`、`#/ocr` | 工具 · 页面读取与证据查看（也作为审核页的原文定位目标） |
| `#/runtime` | 工具 · 服务合同、队列、模型与存储 |

侧栏按生产主线排列（报告 → 提取 → 审核 → 发布），运行监视常驻侧栏，工具默认折叠。

## 关键设计

- **批量生产固定完整链路**：报告处理 → 定向提取 → 候选交付；报告按登记年份自动排序并可全选，条款默认从通用必备/重点/基础/全定量指标集同步，切到自定义范围才逐包选择。
- **新建提取只问三件事**：选报告、选指标集、开始。模型方案、云授权、预算、逐包条款都在“高级设置”里，
  默认本地 Qwen + 均衡预算；执行计划仍然可预览。
- **指标成果是一张全宽结论表**：按条款包分组，行内展开主值、子项、其他口径、来源明细与“定位原文”；
  顶部固定概况、结论筛选、搜索与导出，展开使用弹簧动画。
- **交付与发布四步**（报告身份 → 发布主体 → 交付候选 → 审核发布）就在提取详情里，缺什么就地补齐。
- **来源与身份分开**：文件名只用于找文件；报告标题、发布者、报告期与测量主体都要明确登记，不靠推断。
- **证据可定位**：真实页索引、对象 ID、单元格 `cell_id`，只在几何可靠时绘制位置。
- **读取策略**：每个资源只允许一个在途请求，轮询不会打断慢请求；失败 5 秒自恢复；迟到响应按资源键丢弃。
  事件流只收新事件（`latest`），页面隐藏时断开。
- **权限**：本机回环请求由数据平台识别为本机操作员；从其他机器或脚本调用须 Bearer 令牌，令牌只存在页面内存。

## 代码结构

```
src/
├── App.tsx              外壳、路由、侧栏与步骤条
├── api.ts               三服务 HTTP 客户端（超时、错误、凭据）
├── state.tsx            资源读取：单请求在途、身份隔离、轮询恢复、事件流
├── pages/               Reports · Extractions · Review · Publication · Standards · Runtime …
├── components/          Foundation16Board（指标成果）· SidebarMonitor（运行监视）· PublishFlow（交付发布）
├── styles.css           设计系统（色阶、圆角、阴影、弹簧动效）与应用样式
└── foundation.css       指标成果、会话、交付发布与监视面板
```

## 验收边界

`npm test` 覆盖合同与交互（范围快照、进度语义、权限、交付回执、证据定位、批量部分失败、跨资源身份隔离），
不调用真实模型、不写项目数据。真实闭环需要在启动后的服务上由人执行：
登记报告 → 提取 → 审核 → 交付 → 发布 → 公开网站回查。
